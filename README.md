# Uni-Logbuch

Eine einfache, lokal im Browser laufende Web-App, um Uni-Anwesenheit,
Arbeitszeiten und Notizen festzuhalten.

## Funktionen

- Vier Stationen: Uni-Eingang, Arbeitsbeginn, Arbeitsende und Uni-Ausgang
- Erfassung von Uhrzeiten und Anzeige laufender Zeiten
- Tageszusammenfassung für Anwesenheit und Arbeit
- Tagesnotizen
- Verlauf des aktuellen und früherer Tage
- Letzte Station zurücknehmen oder den heutigen Tag zurücksetzen
- Export aller gespeicherten Tage als CSV
- Speicherung lokal im Browser über `localStorage`

## Verwendung

`index.html` im Browser öffnen. Es ist keine Installation erforderlich.

Die Daten werden in diesem Browser gespeichert und nicht automatisch
auf einen Server übertragen. Beim Löschen der Browserdaten können sie
verloren gehen. Für eine Sicherung den CSV-Export verwenden.
